    How this tool works

    Paste a JSON response or request body, pick a naming convention, and the tool produces idiomatic Dart classes that match the conventions used in real Flutter codebases — including the maaden codebase that inspired this project.

    Naming conventions

    • API model — for HTTP responses. Root class is Api<Name>Model in folder api_<name>/.
    • Param model — for request payloads. Root class is Pm<Name>Model in folder pm_<name>/.
    • Sub-classes always end with Model. A nested object with its own nested objects gets its own folder; otherwise it lives as a file in the parent folder.

    Type inference rules

    • null → dynamic (not Null?)
    • List of all-null / empty list → List<dynamic>?
    • Mixed primitive list → List<dynamic>?
    • Whole-number → int?; fractional → double?

    Param mode toJson

    In Param mode, every toJson assignment is wrapped in a if (field != null) guard so the request body never sends keys with null values.

    ConvertService

    Enable this option for defensive parsing. fromJson calls ConvertService.convertString(...), .convertInt(...), etc. instead of trusting raw JSON values. The matching convert_service.dart is bundled into your downloaded ZIP under utils/.

    Capabilities

    Optional static helpers added to each class:

    • parseItem — parse a single object, never throws.
    • parseItems — handles both raw lists ([{}, {}]) and { data: [{}, {}] }.
    • copyItem / copyItems — deep copy via JSON round-trip.
    • toString override — prints name, title, label, or id if present.

    Projects

    Use the Projects tab to group models by app (myFm, maaden, …). Save each generated set into a project, then download the entire lib/ tree at once. Projects live in your browser's localStorage — no server, no signup.

    Docs export

    Every save remembers the original JSON you pasted. The Download docs action emits a markdown bundle: one file per model, listing the fields, types, sample JSON, and the generated Dart. Useful for handing context to teammates or to AI assistants.
